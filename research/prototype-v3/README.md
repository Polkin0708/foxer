# Прототип правил v3 (Python)

Исследовательский прототип, не часть бота. Нужен для сверки при переносе правил в движок.

- `fvg-bot-rules-v3-proposal.json` — отличия от `strategy/fvg-bot-rules.json` schema_version 2. Текущий парсер эти поля отклонит: под каждое нужен код.
- `engine.py` — прототип: планы W/D, вход по H4 FVG, ренж-модуль, окно сессии, выход по индексу доллара.
- `trades-session.csv` — сделки прототипа на финальном конфиге, 2020-09..2026-11, окно сессии. Время — время сервера MT5 (America/New_York + 7 ч). 550 строк: 453 закрытые сделки и 97 лимитных заявок без исполнения (пустой `r`).
- `prop_final.py` — расчёт челленджа Upscale по списку сделок.

## Запуск

Пути к данным в `engine.py` заданы аргументом, выходной каталог — константой внутри файла.

    python3 engine.py DXY <DXY_synthetic_M1.csv> author 0              # события индекса
    COND_D=1 python3 engine.py EURUSD <EURUSD_M1.csv> author 1 close
    COND_D=1 RANGE_ON=0 python3 engine.py GBPUSD <GBPUSD_M1.csv> author 1 ""
    COND_D=1 TARGET_TP=1 python3 engine.py USDJPY <USDJPY_M1.csv> author 1 ""

Вход — выгрузка M1 из MT5. Издержки: 1 пипс на сделку.

## Ограничения

- Исполнение внутри минуты: стоп раньше тейка при конфликте.
- Индекс доллара синтетический, из шести пар.
- Отклонённые после теста правила перечислены в JSON (`rejected_after_backtest`).
