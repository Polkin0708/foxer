# История индекса

Поддерживается только история индекса с явным происхождением. Старые архивы
не конвертируются. Полнота данных не предполагается по наличию файла.

Каталог набора содержит manifest.json, quality-report.json, raw/ и prepared/.
quality-report.json: source (непустое имя источника), price_basis="index",
timezone="UTC", symbol, gaps (массив интервалов {from_ms,to_ms}),
missing_months (массив), outputs (имя файла → {bytes,sha256}).
Бэктест отклоняет разные источники в наборе одного инструмента. Импорт в SQLite
хранит источник у каждой минуты и не запрещает несколько источников в одной БД.

manifest.json содержит files: массив {month:"YYYY-MM",file:"raw/имя.zip",sha256}.
Границы месяцев — UTC. ZIP содержит ровно один CSV `<SYMBOL>-index-*.csv`.
Первая строка — timestamp_ms,price. Далее UTC Unix milliseconds и положительная
десятичная цена с точностью до шести знаков. Лишние колонки запрещены.
В бэктесте точные повторы тиков внутри архива удаляются; обратный порядок времени
отклоняется. Тики внутри gaps исключаются. Подготовленные минуты, пересекающие
gaps, отклоняются; разрыв прерывает полноту открытых свечей.
Импорт в SQLite проверяет наличие массива gaps, но не исключает его интервалы
из минутных файлов. Повторный импорт идентичных минут не создаёт дубликатов;
дубликаты и обратный порядок минут внутри файла отклоняются.

Подготовленные минуты: `<SYMBOL>-M1-index-<период>.csv` (для бэктеста также `<SYMBOL>.csv`).
Точный заголовок: timestamp_utc,timestamp_ms,bar_end_utc,open,high,low,close,quote_count,gap_before_minutes.
Время — UTC, начало минуты и конец через 60 секунд; OHLC относится только к индексу.
quote_count положителен. Пропуски не заполняются. Контрольные суммы проверяются
до чтения. Для бэктеста необходим полный минимальный контекст W/D/H4 по стратегии
и котировки запрошенного периода; иначе возвращается ошибка.

Бот не загружает эти файлы автоматически. Загрузчика истории Upscale нет.
Локальный бэктест принимает подготовленный набор через --data-config.

## Выгрузка баров MetaTrader 5

Команда `prepare-mt5 <export.csv> <root> <symbol> <source>` преобразует
выгрузку M1 из MT5 («Символы → Бары → Экспорт баров») в набор без raw/ и
manifest.json: prepared/<SYMBOL>-M1-index-YYYY-MM.csv, prepared/gaps.csv и
quality-report.json. Каталог root должен не существовать или быть пустым.
Затем используется обычный import-history или минутный бэктест.

Вход: заголовок `<DATE> <TIME> <OPEN> <HIGH> <LOW> <CLOSE> <TICKVOL> <VOL> <SPREAD>`
через табуляцию, время YYYY.MM.DD HH:MM:SS, строки строго по возрастанию.
Время сервера считается равным America/New_York + 7 часов; несуществующее или
неоднозначное локальное время отклоняется. Индексная цена — экспортированный
OHLC без изменений; колонки `<SPREAD>` и `<VOL>` не используются,
quote_count — `<TICKVOL>`, минута без тиков отклоняется.

quality-report.json: source, symbol, price_basis="index", timezone="UTC",
origin="mt5_m1_bars", timezone_conversion, index_model, gaps (разрывы длиннее
60 минут вне выходных как {from_ms,to_ms}), missing_months, outputs.
Пропущенные минуты не заполняются; gap_before_minutes — число отсутствующих
минут перед строкой.

## Минутный режим бэктеста

Для набора с origin="mt5_m1_bars" тиковые архивы не требуются: бэктест читает
подготовленные минуты и в периоде теста. Это приближение, а не наблюдаемые
котировки; results.json поле execution.intrabar это указывает. Период теста не
должен пересекать missing_months; смешивать тиковые и минутные наборы одного
инструмента нельзя.

Каждая минута превращается в четыре индексные котировки: open (+0 с), два
экстремума (+20 с и +40 с) и close (+59 с). Порядок экстремумов выбирается в
худшую для открытых сигналов инструмента сторону:

- активный лонг, у которого стоп достижим в этой минуте, — сначала low;
- активный шорт, у которого стоп достижим, — сначала high;
- ожидающий лонг: если достижим стоп — сначала low (налив и стоп),
  иначе если достижима цель — сначала high (отмена до входа);
- ожидающий шорт — зеркально.

При разных требованиях выбирается порядок, нужный большему числу сигналов
(при равенстве — low), минута учитывается в coverage.order_conflicts.
Без затронутых сигналов: close ≥ open — open, low, high, close; иначе open, high, low, close.
