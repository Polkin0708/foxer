# История индекса

Поддерживается только история индекса с явным происхождением. Старые архивы
не конвертируются. Полнота данных не предполагается по наличию файла.

Каталог набора содержит manifest.json, quality-report.json, raw/ и prepared/.
quality-report.json: source (непустое имя источника), price_basis="index",
timezone="UTC", symbol, gaps (массив интервалов {from_ms,to_ms}),
missing_months (массив), outputs (имя файла → {bytes,sha256}).
Бэктест отклоняет разные источники в наборе одного инструмента. Импорт в SQLite
хранит источник у каждой минуты и не запрещает несколько источников в одной БД.

manifest.json содержит files: массив {month:"YYYY-MM",file:"raw/имя.zip",sha256}.
Границы месяцев — UTC. ZIP содержит ровно один CSV `<SYMBOL>-index-*.csv`.
Первая строка — timestamp_ms,price. Далее UTC Unix milliseconds и положительная
десятичная цена с точностью до шести знаков. Лишние колонки запрещены.
В бэктесте точные повторы тиков внутри архива удаляются; обратный порядок времени
отклоняется. Тики внутри gaps исключаются. Подготовленные минуты, пересекающие
gaps, отклоняются; разрыв прерывает полноту открытых свечей.
Импорт в SQLite проверяет наличие массива gaps, но не исключает его интервалы
из минутных файлов. Повторный импорт идентичных минут не создаёт дубликатов;
дубликаты и обратный порядок минут внутри файла отклоняются.

Подготовленные минуты: `<SYMBOL>-M1-index-<период>.csv` (для бэктеста также `<SYMBOL>.csv`).
Точный заголовок: timestamp_utc,timestamp_ms,bar_end_utc,open,high,low,close,quote_count,gap_before_minutes.
Время — UTC, начало минуты и конец через 60 секунд; OHLC относится только к индексу.
quote_count положителен. Пропуски не заполняются. Контрольные суммы проверяются
до чтения. Для бэктеста необходим полный минимальный контекст W/D/H4 по стратегии
и котировки запрошенного периода; иначе возвращается ошибка.

Бот не загружает эти файлы автоматически. Загрузчика истории Upscale нет.
Локальный бэктест принимает подготовленный набор через --data-config.
