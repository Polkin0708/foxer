# EUR/USD M1: HistData

Источник: https://www.histdata.com/download-free-forex-data/
Правила формата и времени: https://www.histdata.com/f-a-q/

Используется **Generic ASCII Tick**, а не готовый M1. По документации поставщика
готовые свечи основаны только на bid; Generic ASCII Tick содержит одновременно
`DateTime,Bid,Ask,Volume`. Объём поставщиком удалён и в наших данных не используется.
Число котировок (`quote_count`) не является торговым объёмом. Архив содержит
котировки поставщика, полнота всех изменений глобального рынка не предполагается.

Каталог `data/histdata-eurusd-2024-2026/`:

- `raw/EURUSD-T-YYYYMM.zip`: оригинальные месячные архивы, включая отчёты поставщика.
- `manifest.json`: страницы загрузки, список месяцев, ошибки и SHA-256 архивов.
- `prepared/EURUSD-M1-bid-ask-YYYY.csv`: минутные свечи по годам.
- `prepared/gaps.csv`: разрывы больше одной минуты, включая выходные и праздники.
- `quality-report.json`: фактическое покрытие, количество строк, дубликаты,
  отрицательные спреды, отсутствующие месяцы, SHA-256 результата.

Месячный каталог на 6 ноября 2026 содержит январь–октябрь 2026. Ноябрь–декабрь
не включены. Источник хранится отдельно от Dukascopy: автоматической склейки
разных потоков котировок нет. Все 34 архива нужны для полного доступного периода.

Приведённые объёмы и результаты относятся к ранее подготовленным локальным
данным. Архивы, CSV и отчёты не входят в репозиторий. Эти локальные наборы
HistData удалены 11.11.2026 по запросу пользователя. Ниже описаны прежние
результаты и способ повторной подготовки; наличие файлов не предполагается.

## Подготовка

Дополнение за 2023 год скачано в `data/histdata-eurusd-2023/`:
12 месячных ZIP, 23 676 306 обработанных котировок и 322 519 минутных свечей
Bid/Ask. Покрытие UTC: 2023-01-01 22:04 — 2023-12-29 21:59.
В отчёте отмечены 1 871 разрыв (включая закрытый рынок) и 5 118 котировок,
исключённых из агрегации из-за неоднозначного порядка времени. Исходные ZIP
хранились отдельно от набора 2024–2026; оба набора впоследствии удалены.

Повторная загрузка/подготовка дополнения:

```sh
python3 scripts/histdata_data.py --year 2023 --root data/histdata-eurusd-2023
```

```sh
# Выполняйте команды из корня репозитория
python3 scripts/histdata_data.py
python3 scripts/histdata_data.py --prepare-only
python3 -m unittest discover -s tests -v
```

Python 3.11+ и curl. Проверяется CRC ZIP, состав архива, SHA-256 перед обработкой,
положительность цен и хронологический порядок записей. Цены обрабатываются
целыми числами с масштабом 1 000 000. Последовательные точные дубликаты
timestamp/bid/ask удаляются с подсчётом. Разные котировки в одной миллисекунде
сохраняются в порядке исходного файла. Отрицательные спреды не исправляются,
а учитываются в отчёте.

Перед агрегацией каждый архив отдельно проверяется на возвраты времени назад.
При таком событии весь пересекающийся диапазон минут обеих копий исключается
из подготовленного CSV: сортировка неоднозначных времён создала бы вымышленные
OHLC. Исходные котировки остаются в ZIP. События и количество исключённых
котировок записаны в `timestamp_reversals` и `quarantined_quotes` отчёта.
Наблюдавшийся пример — повтор часа 19:00–19:59 26 октября 2025 по времени
поставщика. Заявленный фиксированный EST используется для остальных записей;
это соглашение документации поставщика, а не независимо доказанная точность
всех его временных меток. Для стратегий, чувствительных ко времени новостей,
нужна дополнительная сверка с независимым потоком.

Время поставщика — фиксированный EST (UTC−5), без DST. Прибавляем ровно пять
часов круглый год. `timestamp_utc` и `timestamp_ms` — начало UTC-минуты;
`bar_end_utc` — время завершения минуты. Котировки группируются в полуоткрытые
интервалы [начало, начало+1 минута). Для bid и ask отдельно берутся первая,
максимальная, минимальная и последняя цены. Пустые минуты не добавляются.

`spread_open/close/min/max/mean_pips` рассчитаны из **парных котировок ask−bid**,
где 1 pip = 0.0001. Средний спред взвешен по числу записей, а не по времени.
Это отличается от вычитания экстремумов двух независимых свечей.
`gap_before_minutes` — сколько минут отсутствует между соседними свечами,
включая границу года. Разрывы не классифицируются автоматически как ошибки:
часть соответствует закрытому рынку и праздникам.

Полные OHLC доступны сигналу только после `bar_end_utc`. Спред входит в цены
покупки/продажи, но комиссии, проскальзывание и свопы нужно задавать отдельно.
Стоп и тейк, задетые в одной минуте, нельзя упорядочить по свечам — для этого
сохранены исходные котировки. Нет гарантий исполнения по каждой архивной цене.
