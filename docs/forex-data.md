# EUR/USD M1 для бэктестов

Источник: Dukascopy, дневные архивы BID/ASK `*_candles_min_1.bi5`.
Данные хранятся отдельно от спортивной базы Ludos.

Локальный набор и журналы загрузки удалены 10.11.2026. Ниже описаны сохранённый
загрузчик и создаваемые им файлы; повторная подготовка требует сначала загрузить
архивы заново. Текущий бэктест проекта использует HistData.

Описанные результаты относятся к локальной подготовке; архивы и производные
файлы в репозиторий не включены.

## Загрузка и повторная подготовка

Python 3.11+ и системный curl; дополнительных пакетов нет.

```sh
python3 scripts/forex_data.py --start 2024-01-01 --end 2026-11-06 \
  --base-url https://www.dukascopy.com/datafeed
python3 scripts/forex_data.py --prepare-only
python3 -m unittest discover -s tests -v
```

Команды запускаются из корня репозитория.
Каталог данных по умолчанию привязан к расположению скрипта.
Конец периода не включается. За 2026 год запрашиваются только завершённые UTC-дни
по 5 ноября включительно, а не будущие ноябрь–декабрь. Повторный запуск читает
сохранённые архивы и повторяет запросы для отсутствующих файлов. Для нового
снимка данных укажите другой `--root`; существующие raw-файлы не обновляются.

## Файлы

Каталог: `data/eurusd-m1-2024-2026/` (исключён из Git).

- `raw/YYYY/YYYY-MM-DD-BID.bi5`, `...-ASK.bi5`: исходные архивы без изменений.
- `manifest.json`: запрошенный диапазон, URL, статусы запросов, размеры и SHA-256.
- `prepared/EURUSD-M1-bid-ask-YYYY.csv`: объединённые свечи по годам.
- `prepared/gaps.csv`: все интервалы между соседними сохранёнными свечами,
  включая выходные, праздники и потенциальные пропуски поставщика.
- `quality-report.json`: фактическое покрытие, количество строк, расхождения
  bid/ask, исключённые неактивные минуты, дни без данных и контрольные суммы CSV.

## Контракт CSV

`timestamp_utc` — начало минуты, ISO 8601 UTC; `timestamp_ms` — Unix milliseconds.
`bar_end_utc` — начало следующей минуты. Полные OHLC свечи доступны стратегии
только после её окончания; торговля по сигналу закрытия предполагает последующее
исполнение, а не исполнение задним числом внутри той же свечи.

`bid_open/high/low/close` и `ask_open/high/low/close` — USD за EUR, пять знаков.
`bid_volume`, `ask_volume` — значения объёма поставщика без переинтерпретации;
это не централизованный объём всего рынка Forex.

`open_side_difference_pips`, `close_side_difference_pips` — арифметическая
разность соответствующих цен ask и bid, делённая на 0.0001. Начальные и конечные
котировки двух независимых свечей могут быть несинхронными: это приближение,
а не измеренный одновременный тиковый спред. Разность максимумов/минимумов
вообще не используется как спред. `gap_before_minutes` показывает число
отсутствующих минут после предыдущей сохранённой свечи (включая границу года).

## Проверки и ограничения

Декодер проверяет длину записей, минутные метки, строго возрастающий порядок,
отсутствие дубликатов, OHLC, конечный неотрицательный объём. Ошибочные файлы
не сохраняются как успешные. Проверка SHA-256 предшествует подготовке CSV.
Формат BI5: LZMA, big-endian `>5If`, секунды от начала UTC-дня, open, close,
low, high, volume. Для EURUSD целочисленная цена делится на 100000.
Месяц в URL поставщика отсчитывается от нуля.

В CSV входят только минуты, присутствующие с обеих сторон, с ненулевым объёмом
хотя бы одной стороны. Пары минут с нулевым объёмом обеих сторон исключены
как неактивные (исходники сохранены). Нет forward fill, интерполяции, удаления
ценовых выбросов и автоматического исправления отрицательной разности ask/bid.
Все такие разности учитываются в отчёте. Пустой день и HTTP 404 не означают
автоматически выходной: статус и день недели сохраняются для отдельной оценки.

Бэктесту нужны комиссии, проскальзывание, исторические свопы и правила брокера.
Покупка исполняется по ask, продажа по bid. Нельзя определить порядок касания
стопа и тейка внутри минуты по OHLC: используйте консервативное правило либо
тиковые данные. Разрывы нельзя считать гарантированно исполнимыми ценами.

Документация источника и формата экспорта:
- https://www.dukascopy.com/swiss/english/marketwatch/historical/
- https://www.dukascopy-node.app/output-formats
- https://github.com/Nosvemos/dukascopy-go/blob/main/pkg/dukascopy/bi5.go

При HTTP 429 новые сетевые запросы прекращаются до следующего ручного запуска.
`--offline` восстанавливает манифест и CSV из локальных архивов, отмечая
отсутствующие файлы как `not_downloaded`. Неполный набор даёт ненулевой код выхода.
В манифесте URL для повторно использованного кэша — адрес запроса текущего запуска;
`reused_cached_file` отмечает, что сетевой запрос не выполнялся. Изначальные архивы
получены с `https://www.dukascopy.com/datafeed`; контрольные суммы фиксируют
сохранённые байты, а не удостоверяют подлинность поставщика.
